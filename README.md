3. Hidden Gems Travel — AI Booking, Payment & Driver Dispatch Automation
A demo automation for a fictional tour company, built with n8n and Python and based on a real-world brief for a tour operator. A customer chats with an AI agent in five languages, gets a booking and a Stripe payment link, a driver claims the job with Accept/Decline buttons, and on-site payments go into a Google Sheets cash ledger.

Key features
- Multilingual AI agent (IT/EN/ES/FR/PT) with tool-based tour data, conversation memory and human handoff
- Server-side validation and pricing in Python, so the AI never sets the price
- Signed (HMAC) Bokun API request and Stripe Checkout with payment webhook
- Driver dispatch with chat buttons where the first driver to accept wins
- Append-only cash ledger driven by chat commands, with per-driver balances
- Error handler that classifies failures, rates severity and emails the cause with troubleshooting steps
- One-click end-to-end test runner that can run daily
